# YTPlusM DIY 
The best fork of an incredible enhancer for YouTube on iOS, featuring over hundred customizable options with more tweaks than the original <a href="https://github.com/dayanch96/YTLite">YouTube Plus.</a>

<strong>This repo is only for building YTPlusM IPAs (with YTPlus from 5.1 to 5.2.1, no 5.2)</strong>

<strong>For more info visit <a href="https://github.com/Mark02-2012/YTPlusM">the main repo.</a>
